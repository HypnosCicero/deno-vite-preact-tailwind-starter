# Welcome to deno-vite-preact-tailwind-starter

While exploring Deno's frontend ecosystem, I noticed a gap: there wasn't a clean, lightweight starter template tailored specifically for building SPAs. Developers typically had to choose between two paths: using the standard Node.js workflow generated by Vite (which brings along package.json and a lot of redundant boilerplate), or adopting Fresh, which is an opinionated full-stack SSR framework not always ideal for pure client-side SPAs.

在探索 Deno 的前端生态时，我发现缺少一个专门面向纯客户端 SPA 的极简模板。以往通常只有两条路可选：要么沿用 Vite 官方基于 Node.js 的传统配置（附带 package.json 等较多冗余文件），要么使用 Fresh 这套并不完全适合纯客户端 SPA 的全栈 SSR 框架。

To fill this gap, I created this lightweight starter project to provide a clean, out-of-the-box SPA setup powered by Deno.

因此，我搭建了这个基础样板项目，旨在为 Deno 环境下的纯单页应用提供一个轻量且开箱即用的开发起点。

# Features

- Native Deno Configuration: Managed entirely through deno.json, allowing you to seamlessly import dependencies from both jsr: and npm:.
- 原生 Deno 配置：完全通过 deno.json 进行依赖与任务管理，支持无缝使用 jsr: 及 npm: 模块。
- Pre-configured Modern Frontend Stack:
- 开箱即用的现代前端工具链：
  - Dev Server & Bundler: Vite (lightning-fast HMR and building)
  - 开发服务器与构建工具：Vite（提供极速热更新与打包体验）
  - UI Library: Preact (compact, fast React-compatible library with Signals support)
  - UI 框架：Preact（轻量高效，支持 Signals 状态管理）
  - Styling: Tailwind CSS
  - 样式库：Tailwind CSS 
- Bonus: Includes out-of-the-box configuration files optimized for the Zed editor with Deno LSP.
- 附带配置：内置针对 Zed 编辑器的 Deno LSP 配置文件，开箱即用。
